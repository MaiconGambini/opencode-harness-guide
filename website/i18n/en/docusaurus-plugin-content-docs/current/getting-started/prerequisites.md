# Prerequisites

Before installing the OpenCode Harness, you need the following environment:

| Requirement | Detail |
|---|---|
| **OpenCode** | Installed and working. The harness is a set of rules, skills, and commands that operate on top of OpenCode — it does not replace the base installation. |
| **Git** | Configured with your user (`git config --global user.name` and `git config --global user.email`). |
| **Node.js 20+** | Required for the harness plugins and scripts. |
| **PowerShell 5.1+** | On Windows. The harness was designed and tested in this environment. |

No database, container, or external service is required. The harness
operates as local configuration files and scripts.
