# Prerequisites

Before installing OpenCode Harness, you need:

- **OpenCode** installed and working. The harness is a set of rules,
  skills, and commands that operate on top of OpenCode — it does not replace
  the base installation.
- **Git** configured with your user (`git config --global user.name` and
  `git config --global user.email`).
- **Node.js 20+** for the harness plugins and scripts.
- **PowerShell 5.1+** on Windows. The harness was designed and tested in this
  environment.

No database, container, or external service is required. The harness
operates as local configuration files and scripts.
