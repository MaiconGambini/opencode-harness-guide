# Referências e créditos

Este projeto não nasceu do zero. Ele se apoia em ideias, coleções de skills e
material de estudo criados por outras pessoas da comunidade. Esta página
reúne as fontes e inspirações, com um agradecimento a quem as tornou
públicas.

| Repositório | Contexto |
