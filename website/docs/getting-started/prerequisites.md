# Pré-requisitos

Antes de instalar o Harness OpenCode, você precisa do seguinte ambiente:

| Requisito | Detalhe |
|---|---|
| **OpenCode** | Instalado e funcionando. O harness é um conjunto de regras, skills e comandos que operam sobre o OpenCode — ele não substitui a instalação base. |
| **Git** | Configurado com seu usuário (`git config --global user.name` e `git config --global user.email`). |
| **Node.js 20+** | Necessário para os plugins e scripts do harness. |
| **PowerShell 5.1+** | No Windows. O harness foi projetado e testado neste ambiente. |

Nenhum banco de dados, container ou serviço externo é necessário. O harness
opera como arquivos de configuração e scripts locais.

## Próximo passo

Siga para [Instalação](./installation) e clone o repositório.
