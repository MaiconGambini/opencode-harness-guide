# Pre-requisitos

Antes de instalar o Harness OpenCode, voce precisa de:

- **OpenCode** instalado e funcionando. O harness e um conjunto de regras,
  skills e comandos que operam sobre o OpenCode — ele nao substitui a
  instalacao base.
- **Git** configurado com seu usuario (`git config --global user.name` e
  `git config --global user.email`).
- **Node.js 20+** para os plugins e scripts do harness.
- **PowerShell 5.1+** no Windows. O harness foi projetado e testado neste
  ambiente.

Nenhum banco de dados, container ou servico externo e necessario. O harness
opera como arquivos de configuracao e scripts locais.
